# Knowledge Village v3 feedback

v3修正指示です。今回の方向性はかなり良いので、その上で以下を改善してください。

【今回の評価】
- 全体の雰囲気はかなり良くなった
- 建物の見え方は前より自然
- 村を育てている感は出てきた
- 建物の重なり対策や長押し移動の方向性は良い

【最優先で直してほしい点】

1. メッセージウインドウのバグ修正
- メッセージウインドウが縦書きのように崩れることがある
- テキストが枠内で正しく折り返されるようにする
- 常に横書きで表示する
- ダイアログの幅・高さ・余白・文字サイズをスマホ向けに安定させる
- ボタン（建てる / やめる など）がダイアログ内に自然に収まるようにする
- 画面外にはみ出さないようにする
- 建物選択時、説明ポップアップと建築メニューが重なって操作しづらくならないよう整理する

2. 土地拡張の演出を改善
- 今は土地マスが増えても、周囲の風景がほぼ変わらず、拡張した実感が弱い
- 土地拡張は「周囲の森や木を少しずつ開拓していく」見せ方にしてほしい
- 拡張前は中央だけが開けていて、周囲は木・茂み・岩・森で囲まれている状態
- 拡張するたびに、周囲の木や障害物が減り、森の境界が外側へ下がり、使える土地が広がっていくようにする
- つまり「マス追加」ではなく「村が森を切り開いて広がっていく体験」にしたい

3. 土地拡張時の見た目の変化
- 拡張後に建築可能エリアの見た目が実際に広くなるようにする
- 森・木・茂み・岩の位置を、土地サイズに応じて段階的に後退させる
- 背景の道・柵・草地も、拡張に合わせて少し広がると嬉しい
- プレイエリアの中央と手前は見やすさ優先で、障害物が被らないようにする

4. 土地拡張時の気持ちよさ
- 拡張した瞬間に、新しい土地が少し明るくなったり、木が消えて開けたりして、「広がった！」と感じられる演出を入れたい
- 軽いアニメーションや視覚効果があると良い
- 重くなりすぎない範囲で実装する

【実装の考え方】
- 土地サイズに応じて scenery / obstacle / forest boundary を再配置する
- 例えば 16マス → 25マス → 36マス → 49マス → 64マス のように、拡張段階ごとに周辺環境を少しずつ変える
- 使える土地が増えるたびに、背景の森が後ろへ下がる印象を出す
- 建築エリア前面に大きな木が被らないようにする
- 画面中央のプレイエリアは常に視認性を確保する

【維持してほしい点】
- 今のUIの方向性（上部HUD、下部ボタン、右側の縦メニュー）は維持
- 絵本風でやさしい世界観は維持
- 建物重なり防止は維持
- 長押し選択 → 移動先タップの操作は維持しつつ、必要ならさらに安定化してよい
- 学習の模擬報酬システムは維持
- storybook-demo 配下のみ変更すること
- 本編や既存データには触れないこと

【今回の目的】
v3では、
- メッセージUIを安定させる
- 土地拡張で実際に風景が変化する
- 森を切り開いて村が広がっていく感覚を出す
この3点を特に重視してください。

## 検証必須
- 幅360pxのスマホでもモーダルの説明文が横書き・正常改行される
- 建物選択パネルと確認ダイアログが干渉しない
- 土地16/25/36/49/64マスで描画と森の境界が段階的に変化する
- 既存建物の当たり判定と長押し選択を維持
- 保存データと本編は一切変更しない
